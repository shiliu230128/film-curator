# Film Curator

Film Curator 让你在打开视频软件之前就定好今晚看什么，顺手把看过什么、打了几分攒成一份自己的观影记录本。

它是给 AI 助手装的一套本领（业内叫 skill，也就是给 AI 增加一套专门能力）。装好之后你直接用中文跟 AI 说话，它记得你的口味、你的禁区、你这周还剩几个空档。

除了对话，它还有两个你会碰到的出口。一个是本地网页 `film-curator/web/index.html`，双击就能打开，观影计划、统计和全部记录都能在上面改。另一个是导出的文件，网页上能把记录导成 JSON、CSV 或 Excel，备份和搬家都靠它。

你的片单和评分存成文本文件放在你自己电脑上，不用注册账号。

## 它用起来什么样

### 一、不知道想看什么，只知道有多少时间

你说：「今晚有两个小时，想看安静但有余味的」

它先在你已经存下的片单里找，不够或不合适才往外找。超过 120 分钟的、你标过不看的题材、最近刚看过的同类都会被排掉。最后给一个明确首选加一到三个方向不同的备选，每部都说清为什么是它、为什么适合今天，以及可能会踩的坑。

不方便一直盯字幕的时候直接说「这次不太方便看字幕」，它会优先中文、粤语或你更容易听懂的内容，不会把外语片彻底禁掉。

### 二、排一段时间的片单

你说：「帮我排一下这个月的观影计划」

按周分配，默认不排满，留几个机动位给临时变化，长片后面接轻的。它先给草案，顺带说明某部为什么没排进去，你确认了才写进记录。周、月、季度都能排，季度会分成入门、深入、回望三段。

网页上也能自己排：打开 `film-curator/web/index.html`，观影计划那栏有本周、本月、本季三个页签，点新增计划就行。

### 三、维护自己的影视库

跟 AI 说，或者在网页上点，两条路都行。

说的话是这种：「把《海街日记》加入想看」「我看完《燃烧》，9 分，留白很有意思」「我有一份以前的影单，帮我导进来」。

网页上能做的：新增记录、改状态、存自己的筛选视图、导入导出（认 JSON、CSV 和 Excel）。更推荐让 AI 帮你导入，因为 AI 会先预览重复项和无效项，再默认补齐客观信息；网页导入更像一个本地临时整理入口，适合少量手动合并。

记录看完时它会问「我的评分」，也就是你给这片子打几分。旁边还有个可选的「当时适配度」，平时不用管——只在那种「片子确实好，但我那天累得看不进去」的情况才填。填了它就知道别把那次的低体验算成你不喜欢这一类。

### 四、看完想聊聊，或者想回头查统计

你说「分析一下《燃烧》」，它会先问你要不要剧透，再按你选的深度聊，事实和它自己的解读分开说。

问「这个月我都看了什么」它就只读记录做汇总，示例数据不算进去，给平均分时会告诉你样本有几部。同一份统计在 `film-curator/web/index.html` 的观影统计那栏也能看。

## 怎么用

### 开始之前你需要准备什么

| 需要什么 | 你可能已经有了吗 | 怎么弄到 |
|---|---|---|
| 一个支持 skill 的 AI 客户端 | 在用 Claude Code、Comate 这类工具的话已经有了 | 见你所用客户端的官网 |
| Python 3 | 都要自己确认一下，Mac 也不例外 | 见下面一段 |

浏览器你一定有。不需要 git，不需要装任何第三方 Python 包，这个项目自己不需要账号和 API 密钥。

怎么确认有没有 Python 3：让你的 AI 助手跑一句 `python3 --version`，它会告诉你结果。打印出 `Python 3.x.x` 就有了，直接往下走。

没有的话分两种情况。Mac 上你可能会看到系统弹窗提示装「命令行开发者工具」，点安装、等几分钟就行，不用自己找安装包；也可以到 python.org 下载安装包。Windows 上到 python.org 下载安装包，安装第一屏务必勾上 Add Python to PATH，漏了之后要重装。

### 最快的装法

把项目文件夹下载到本地，然后跟你的 AI 助手说这一句：

```
把这个文件夹装成 skill，装完告诉我怎么用
```

支持 skill 的客户端一般能自己完成剩下的事，包括找目录、建目录、检查缺什么。

装完重开一次对话，说一句「今晚有两个小时，想看点安静的」。它给你推荐了就是装好了。

第一次用它可能反过来先问你几道题，比如最近更想放松还是被触动。这是在了解你的口味，可以跳过。

### 想自己动手装

把整个 `film-curator` 文件夹复制到客户端存放 skill 的目录里。常见客户端的目录：

| 客户端 | Mac / Linux | Windows |
|---|---|---|
| Claude Code | `~/.claude/skills/` | `C:\Users\你的用户名\.claude\skills\` |
| Comate | `~/.comate/skills/` | `C:\Users\你的用户名\.comate\skills\` |

`~` 指你的用户主目录。Mac 上在 Finder 里按 `Shift + Command + G`，把路径粘进去回车就能到。目录不存在就自己新建一个。

用的是别的客户端，去它的设置页或文档里搜 skill、扩展、插件这几个词，能找到对应目录。

拿到的是压缩包就先解压，再复制整个文件夹，不要只挑里面的单个文件。

成功信号跟上面一样：重开对话，说一句想看什么，它给你推荐了就算装好。

### 打开自己的记录本

双击 `film-curator/web/index.html`，用浏览器打开。页面标题是「你的观影记录本」，上面有观影计划、观影统计和所有记录。

四件需要知道的事：

网页第一次要你连接一次项目文件夹。点右上角的「连接项目文件夹」，选中这个项目根目录就行。连上以后网页里的新增、编辑、删除会直接写回项目里的主数据，AI 看到的也是同一份。

带「示例」标签的条目是自带的演示数据，不算进统计，也不影响推荐。页面上有「清除示例」按钮，一次删掉。

「最爱清单」默认显示你给 9 分以上的作品，「已弃」显示状态为已弃的记录。这些不是单独的文件夹，只是从同一套记录里筛出来的视图。

你可以先点一个视图，再改状态、类型、计划周期或评分筛选，然后点「＋ 新建视图」存成自己的入口。

### 出问题了怎么办

第一列是屏幕上会出现的原话，照着找。

| 你看到 | 意思是 | 怎么解决 |
|---|---|---|
| `command not found: python3` | 电脑上还没装 Python | Windows 上把命令里的 `python3` 换成 `python`；还报错就是真没装，回到上面的准备表 |
| `'python' 不是内部或外部命令` | Windows 装 Python 时没勾 Add to PATH | 重装 Python，安装第一屏勾上那个选项 |
| `Missing data file: .../watchlist.json` | 记录文件被删了或没复制全 | 让 AI 跑一次初始化把缺的文件建回来（`python3 scripts/film_curator.py init`，只补缺的，不动已有的） |
| `Invalid JSON in .../watchlist.json` | 文件被改坏了，通常是手动编辑漏了逗号或引号 | 用导出的备份覆盖回去。没有备份就删掉这个文件再让 AI 跑一次初始化，该文件里的记录会丢 |
| `Unknown item id: xxx` | 找不到这条影片记录 | 让 AI 先列一遍当前片单，拿到正确的编号 |
| `Duplicate item id: xxx` | 导入的文件里有两条编号一样的记录 | 让 AI 用 `skip` 或 `replace` 处理一次，别手动改 |
| `rating must be between 0 and 10` | 评分超出范围 | 改成 0 到 10 之间 |
| `Unsupported status: xxx` | 状态词它不认识 | 它只认想看、在看、看过、弃看四种。让 AI 改一次就行 |
| `plan period must be week, month, or season` | 计划周期只支持这三种 | 说清是排本周、本月还是本季 |
| `Import file does not contain watchlist items` | 导入的文件不是这个项目认的格式 | 先用页面的导出功能生成一份，照那个格式改 |
| `Candidate already exists as item id: xxx` | 这部片已经在你片单里了 | 不用重复加 |
| `title cannot be empty` | 新增时没给片名 | 补上片名再说一次 |
| 网页打开是空白的 | 通常是没有整个文件夹一起复制，只拿了 `index.html` | 确认 `web` 文件夹里的 `.js` 和 `.css` 文件都在 |

### 它不能做什么

- 不知道在哪能看。不查片源平台，不管会员和资源。
- 不能多人共用，没有账号，没有云同步。
- 网页要先连接项目文件夹才能真正写回主数据。浏览器不支持这个功能时，它只能看当前快照。
- 不保证所有年份、导演、评分、海报都能补齐。能查到公开资料时会补，查不到就留空，宁可空着也不编。

### 一件需要注意的事

它能干什么，一半取决于你把它装在什么环境里。

装在能联网的 AI 客户端里，它是完整的：库内片单不够用时可以从片单之外给你新建议，导入时也能查公开资料补全客观信息。项目脚本在补全时会访问豆瓣这类公开资料站点，它不查片源平台，也不会上传你的完整记录库。

装在不联网的环境里，比如本地部署的模型，它会缩到只吃本地数据：维护片单、改状态、记分、排计划、做统计、基于已存记录问答都照常。片单之外的推荐做不了，本地模型对影视的了解也就到它训练时为止。

如果你导入的旧影单只有片名，这次没查到也不会就此放弃。下次你再让 AI 处理这个项目时，只要那条记录还缺客观信息，它会自动再试一次，不用你额外下指令。

## 项目里都有什么

**你的东西**都在 `data` 文件夹，7 个文本文件，用记事本就能打开。想备份就整个复制 `data`，或者在网页上点导出。

| 文件 | 装的是 |
|---|---|
| `watchlist.json` | 你的片单（想看、在看、看过、弃看） |
| `candidate_pool.json` | 还没正式加入片单的候选，比如你随口说「可能想看」的、AI 临时检索到的 |
| `history.json` | 观影历史和评分 |
| `user_profile.json` | 你的口味画像 |
| `preference_evidence.json` | 每条偏好结论的依据 |
| `recommend_log.json` | 推荐记录，用来避免重复推荐 |
| `config.json` | 页面设置、类型和标签选项 |

这里有个关键区别：`candidate_pool.json` 不是正式片单。只有你明确说「加入待看」「采用这部」「放进本月计划」，候选才会写进 `watchlist.json`。这样可以避免你随口提到一部片，系统就误以为你真的想看、甚至拿它来影响统计。

**跑起来靠的东西**是 `scripts/` 和 `web/` 两个文件夹，一个是执行增删改查的脚本，一个是网页。不用懂，也不用动。

**想调整它的行为**就改 `SKILL.md` 和 `references/` 里的文件。`SKILL.md` 是总纲，管它每次干活的顺序和边界；`references/` 里几份是分工的规则，比如怎么挑片、怎么排计划、数据怎么存。改这些等于改它的做事方式，改完下次对话生效。
