# Film Curator

Film Curator 让你在打开视频软件之前就定好今晚看什么，顺手把看过什么、打了几分攒成一份自己的观影记录本。

它是给 AI 助手装的一套本领（业内叫 skill，也就是“给 AI 增加一套专门能力”）。装好之后你直接用中文跟 AI 说话，它记得你的口味、你的禁区、你这周还剩几个空档。项目里还带一个本地网页，路径是 `film-curator/web/index.html`，双击就能打开。第一次先连一次项目文件夹，连上以后，网页和 skill 就会共用同一份主数据，你的观影计划、全部片单和统计都能在上面改。

如果你导入自己的旧影单，只给了片名也没关系。默认情况下，它会尝试联网查公开资料，自动补上简介、类型、导演、时长、语言、地区和上映日期。查不到就留空，不会为了好看乱编。

如果这次没查到，它也不会就此放弃。下次你再让我处理这个项目时，只要那条记录还是缺这些客观信息，它会自动再试一次，不需要你额外下指令。

你的片单和评分存成文本文件放在你自己电脑上，不用注册账号。

## 它用起来什么样

### 一、不知道想看什么，只知道有多少时间

你说：「今晚有两个小时，想看安静但有余味的」

它先在你已经存下的片单里找，不够或不合适才往外找。超过 120 分钟的、你标过不看的题材、最近刚看过的同类，都会被排掉。最后给一个明确首选，加一到三个方向不同的备选，每部都说清为什么是它、为什么适合今天，以及可能会踩的坑。

语言也会算进去。比如你能看外语片，但今天在做饭、通勤或者不方便一直盯字幕，你可以直接说“这次不太方便看字幕”。它不会把外语片彻底禁掉，但会优先考虑中文、粤语或你更容易听懂的内容。

### 二、排一段时间的片单

你说：「帮我排一下这个月的观影计划」

按周分配，默认不排满，留几个机动位给临时变化，长片后面接轻的。它先给草案，顺带说明某部为什么没排进去，你确认了才写进记录。周、月、季度都能排；季度会分成入门、深入、回望三段。

网页上也能自己排：打开 `film-curator/web/index.html`，观影计划那栏有本周、本月、本季三个页签，点新增就行。

### 三、维护自己的影视库

跟 AI 说，或者在网页上点，两条路都行。

说的话是这种：「把《海街日记》加入想看」「我看完《燃烧》，9 分，留白很有意思」「我有一份以前的影单，帮我导进来」。

网页上能做的：新增记录、改状态、建自己的筛选视图、导入导出（认 JSON、CSV 和 Excel）。

更推荐的导入方式是让 AI 帮你导入，因为 AI 会先预览重复项和无效项，再默认补齐客观信息。网页导入更像一个本地临时整理入口，适合少量手动合并。

记录看完时它会优先问“作品评价”，也就是这片子本身好不好；“当时适配度”会作为可选补充，主要给推荐系统参考。分开记是因为加班那天看不进去的好片，不该被算成你不喜欢这一类。

### 四、看完想聊聊，或者想回头看统计

你说：「分析一下《燃烧》」，它会先问你要不要剧透，再按你选的深度聊，事实和它自己的解读分开说。

问「这个月我都看了什么」它就只读记录做汇总，示例数据不算进去，给平均分时会告诉你样本有几部。同样的统计在网页上也有一栏（`film-curator/web/index.html`）。

## 适合谁

- 每周都想看点什么，但一打开视频软件就在片单里翻，翻了二十分钟最后关掉去刷手机
- 想留一份自己的观影记录，但手动记表格总是记几次就断了
- 有明确禁区，比如绝对不看恐怖片，希望对方记住，不用每次重新交代

## 不适合谁

- 想找片源、想知道在哪能看的人。它不管这个，只管"看什么"和"看过什么"。
- 想看社区评分和长影评的人，豆瓣更合适。
- 不想用 AI 助手的人。它必须装在 AI 客户端里才能用，不是一个能单独双击打开的软件。
- 需要多人共用一份片单的人。数据在你本机，没有账号，也没有云同步。
- 只想让它在完全离线的环境里给你推荐新片的人。离线时它只能在你已经存下的片单里挑，见文末那节。

## 为什么不用别的

| 别的选择 | 它更适合 | Film Curator 更适合 |
|---|---|---|
| Excel / Notion 手记 | 只想留一份清单，挑片这件事你自己来 | 想在"今晚看什么"那一刻直接拿到有理由的答案，而不是面对一张长表 |
| 豆瓣"想看" | 想看别人的评分影评、想找片源 | 想让它记住你的禁区、可用时长和当下状态，并据此筛选 |
| 每次直接问 AI"推荐几部电影" | 偶尔看一次，随便挑挑 | 不想每次重新交代口味，希望它知道你已经存了什么、看过什么、打过几分 |
| 什么都不做，刷到什么看什么 | 你本来就不在意看什么 | 每周都在挑片上耗时间，还经常最后没看 |

## 安装

最省事的办法是让 AI 替你装。把项目文件夹下载到本地，然后跟你的 AI 助手说：

```
把这个文件夹装成 skill，装完告诉我怎么用
```

支持 skill 的客户端一般能自己完成剩下的事，包括找目录、建目录、检查缺什么。

想自己动手，就是把整个 `film-curator` 文件夹复制到客户端存放 skill 的目录里。常见客户端的目录：

| 客户端 | Mac / Linux | Windows |
|---|---|---|
| Claude Code | `~/.claude/skills/` | `C:\Users\你的用户名\.claude\skills\` |

（`~` 指你的用户主目录。Mac 上在 Finder 里按 `Shift + Command + G`，把路径粘进去回车就能到。目录不存在就自己新建一个。）

用的是别的客户端，去它的设置页或文档里搜 skill、扩展、插件这几个词，能找到对应目录。

拿到的是压缩包就先解压，再复制整个文件夹，不要只挑里面的单个文件。

装完重开一次对话，说一句"今晚有两个小时，想看点安静的"。它给你推荐就是装好了。

第一次用的时候它可能反过来先问你几道题，比如最近更想放松还是被触动。这是在了解你的口味，可以跳过。

### 开始之前需要什么

| 需要什么 | 你可能已经有了吗 | 怎么弄到 |
|---|---|---|
| 一个支持 skill 的 AI 客户端 | 在用 Claude Code 这类工具的话已经有了 | 见你所用客户端的官网 |
| Python 3 | 都要自己确认一下，Mac 也不例外 | 见下面一段 |
| 一个浏览器 | 一定有 | — |

怎么确认有没有 Python 3：让你的 AI 助手跑一句 `python3 --version`，它会告诉你结果。打印出 `Python 3.x.x` 就有了，直接往下走。

没有的话分两种情况。Mac 上你可能会看到系统弹窗提示装"命令行开发者工具"，点安装、等几分钟就行，不用自己找安装包；也可以到 python.org 下载安装包装。Windows 上到 python.org 下载安装包，安装第一屏务必勾上 Add Python to PATH，漏了之后要重装。

不需要 git，不需要装任何第三方 Python 包，这个项目自己不需要账号和 API 密钥。

## 怎么看自己的记录

双击 `film-curator/web/index.html`，用浏览器打开。页面标题是"你的观影记录本"，上面有观影计划、观影统计和所有记录。

两件需要知道的事：

1. 带"示例"标签的条目是自带的演示数据，不算进统计，也不影响推荐。页面上有"清除示例"按钮，一次删掉。
2. "最爱清单"默认显示你给 9 分以上的作品；"已弃"显示状态为已弃的记录。这些不是单独的文件夹，只是从同一套记录里筛出来的视图。
3. 你可以先点一个视图，再改状态、类型、计划周期或评分筛选，然后点"新建视图"保存成自己的入口。
4. 网页第一次需要你连接一次项目文件夹。点右上角的“连接项目文件夹”，选中这个项目根目录就行。连上以后，网页里的新增、编辑、删除会直接写回项目里的主数据，skill 看到的也是同一份。

## 你的东西存在哪

全部在项目的 `data` 文件夹里，7 个文本文件，用记事本就能打开：

| 文件 | 装的是 |
|---|---|
| `watchlist.json` | 你的片单（想看、在看、看过、弃看） |
| `candidate_pool.json` | 还没正式加入片单的候选，比如你随口说“可能想看”的、AI 临时检索到的 |
| `history.json` | 观影历史和评分 |
| `user_profile.json` | 你的口味画像 |
| `preference_evidence.json` | 每条偏好结论的依据 |
| `recommend_log.json` | 推荐记录，用来避免重复推荐 |
| `config.json` | 页面设置、类型和标签选项 |

想备份就整个复制 `data` 文件夹，或者在网页上点导出。

这里有一个关键区别：`candidate_pool.json` 不是正式片单。只有你明确说“加入待看”“采用这部”“放进本月计划”，候选才会写进 `watchlist.json`。这样可以避免你随口提到一部片，系统就误以为你真的想看、甚至拿它来影响统计。

## 出问题了怎么办

第一列是屏幕上会出现的原话，照着找。

| 你看到 | 意思是 | 怎么解决 |
|---|---|---|
| `command not found: python3` | 电脑上还没装 Python | Windows 上把命令里的 `python3` 换成 `python`；还报错就是真没装，回到上面的准备表 |
| `'python' 不是内部或外部命令` | Windows 装 Python 时没勾 Add to PATH | 重装 Python，安装第一屏勾上那个选项 |
| `Missing data file: .../watchlist.json` | 记录文件被删了或没复制全 | 让 AI 跑一次初始化把缺的文件建回来（`python3 scripts/film_curator.py init`，只补缺的，不动已有的） |
| `Invalid JSON in .../watchlist.json` | 文件被改坏了，通常是手动编辑漏了逗号或引号 | 用导出的备份覆盖回去。没有备份就删掉这个文件再让 AI 跑一次初始化，该文件里的记录会丢 |
| `Unknown item id: xxx` | 找不到这条影片记录 | 让 AI 先列一遍当前片单，拿到正确的编号 |
| `rating must be between 0 and 10` | 评分超出范围 | 改成 0 到 10 之间 |
| `Unsupported status: xxx` | 状态词它不认识 | 它只认 want、watching、watched、dropped 四个（对应想看、在看、看过、弃看）。让 AI 改一次就行 |
| `Import file does not contain watchlist items` | 导入的文件不是这个项目认的格式 | 先用页面的导出功能生成一份，照那个格式改 |
| `Candidate already exists as item id: xxx` | 这部片已经在你片单里了 | 不用重复加 |
| 网页打开是空白的 | 通常是没有整个文件夹一起复制，只拿了 `index.html` | 确认 `web` 文件夹里的 `.js` 和 `.css` 文件都在 |

## 它不能做什么

- 不知道在哪能看。不查片源平台，不管会员和资源。
- 不能多人共用，没有账号，没有云同步。
- 网页需要先连接项目文件夹才能真正写回主数据；如果浏览器不支持这个功能，它只能看当前快照。
- 它不会保证所有年份、导演、评分、海报都能补齐。能查到公开资料时会补，查不到就留空，它宁可空着也不编。

## 一件需要注意的事

它能干什么，一半取决于你把它装在什么环境里。

装在能联网的 AI 客户端里（Claude Code 这类），它是完整的：库内片单不够用时，AI 可以从片单之外给你新的建议，也能在导入时查公开资料补全客观信息。

装在不联网的环境里，比如你用的是本地部署的模型，或者客户端断了网，它会缩到只吃本地数据：维护片单、改状态、记分、排计划、做统计、基于你已经存下的记录问答，这些都照常，因为全靠读 `data` 文件夹里那几个文件。片单之外的推荐做不了，本地模型对影视的了解也就到它训练时为止。

项目脚本在“导入补全”和“候选补全”时会访问 Wikidata / Wikipedia 这类公开资料站点；它不查片源平台，也不会上传你的完整记录库。网页本身会在连接项目文件夹后直接读写本地主数据；如果浏览器不支持文件夹连接，它就只能看快照，不能真正改写项目文件。
