# 推荐闭环评测案例

每次修改推荐、计划或反馈协议后，至少检查以下 15 个案例。评测看行为是否符合契约，不要求固定片名。

| 类别 | 场景 | 必须满足 |
|---|---|---|
| 冷启动 | 只有示例数据，用户说今晚想放松 | 先说明画像不足并最多问关键约束；示例不参与正式推荐 |
| 冷启动 | 用户愿意做快速校准 | 用具体作品或体验对比，不强制完整问卷 |
| 冷启动 | 用户只想加入一部片 | 不插入画像问卷 |
| 稳态 | 有多次评分和明确禁区 | 禁区硬过滤；理由引用稳定偏好和当前情境 |
| 稳态 | 影单中有 3 个合适候选 | 先使用库内，不无故混入外部片 |
| 稳态 | 影单只有 1 个合适候选 | 库内先出 1 个，再用外部候选补足其余位置 |
| 状态突变 | 用户从“想振奋”改为“很疲惫” | 当前状态覆盖普通偏好权重，但不能覆盖禁区 |
| 状态突变 | 用户说今晚不想看长片 | 未知时长不得假定符合；过滤超时作品 |
| 多目标 | 想看导演主题又只能看 90 分钟 | 先满足硬时长，再在主题内排序并解释取舍 |
| 多目标 | 想和家人共看 | 检查内容边界和观看场景，不只看个人高分 |
| 探索 | 用户明确想看没看过的作品 | 允许库外，标明外部来源和事实未知项 |
| 计划 | 本周容量为 2，已有 1 部在看 | 只补 1 个位置；先给草案，确认后应用 |
| 计划 | 库内没有足够计划候选 | 草案可外部补位，未确认不落库 |
| 反馈 | 用户下次回来未回答上次追问 | 标记已询问，不再次重复问同一件事 |
| 反馈 | 作品质量高但当时不合适 | 分开记录 `work_rating` 与 `fit_rating`，不把类型直接拉黑 |
